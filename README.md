**[Lima](https://getlima.app)** — my flagship product, a productivity app with **25,000+ users** that brings calendar, habits, money and journaling into a single place. It ships with an AI assistant, a WhatsApp bot for logging on the go, and two-way Google Calendar and Google Tasks sync.

### Featured open-source

- **[Cassandra](https://github.com/cmoraes10/cassandra)** — Simulates thousands of possible futures for a stock using Monte Carlo and Markov chains to estimate where the price is heading, with backtesting, risk management and an interactive panel. `Python`
- **[Penumbra](https://github.com/cmoraes10/penumbra)** — An open-data index that reveals the most overlooked municipalities in Bahia, focused on the cocoa region, feeding an interactive map. Python pipeline plus a Next.js site. `Python` `TypeScript`
- **[reconhecimento_sono](https://github.com/cmoraes10/reconhecimento_sono)** — A computer-vision drowsiness detector that sounds an alarm when the user starts to fall asleep. `Python`
- **[tomorrowUFBA](https://github.com/cmoraes10/tomorrowUFBA)** — Award-winning web project where I led a team of 8 developers and won a UFBA programming competition. `HTML`
